# Linux Labs

> Learning Linux by building it.

Linux Labs is my personal learning repository where I explore how Linux works by reading books, experimenting with the operating system, and building real tools from scratch in Go.

The goal of this repository is not just to learn Linux commands, but to understand how Linux works under the hood.

## Learning Process

Each lab follows the same workflow:

1. Read a chapter.
2. Explore the concepts on a real Linux system.
3. Build something related in Go.
4. Experiment with it.
5. Document what I learned.
